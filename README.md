# BenStream

BenStream est une application mobile de streaming développée avec Flutter. Elle permet aux utilisateurs d’accéder à du contenu multimédia (vidéos, musique, etc.) via une interface simple, fluide et intuitive.

---

## Fonctionnalités

- Lecture de contenu multimédia  
- Navigation par catégories  
- Interface utilisateur simple et fluide  
- Utilisation de données locales (JSON)  
- Compatible Android et iOS  

---

## Technologies utilisées

- Flutter  
- Dart  
- Fichiers JSON locaux pour les données  

---

## Installation

1. Cloner le projet :
```bash
git clone https://github.com/Zerbo-dev/ben_stream.git
```

2. Accéder au dossier :
```bash
cd ben_stream
```

3. Installer les dépendances :
```bash
flutter pub get
```

4. Lancer l’application :
```bash
flutter run
```

---

## Structure du projet

```
lib/
├── models/        # Modèles de données
├── data/          # Fichiers JSON locaux
├── screens/       # Interfaces utilisateur
├── widgets/       # Composants réutilisables
└── main.dart      # Point d’entrée
```

---

## Source des données

Les données utilisées dans l’application sont stockées localement sous forme de fichiers JSON.  
Aucune API externe n’est utilisée.

---

## Objectif

Proposer une application simple de streaming basée sur des données locales, avec une interface fluide et accessible.
